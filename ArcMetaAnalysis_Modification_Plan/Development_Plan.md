# Development Plan - FERREX-META

## 需求记录与审计建议

### 1. 性能瓶颈分析 (Plan-154)
- **目标**：解决 FERREX-META 在百万级数据下的搜索假死问题。
- **核心病因**：
    1. 读写锁竞争：写锁优先导致 UI 读请求被后台搜索长时间阻塞。
    2. 任务溢出：搜索任务不可中途取消，导致线程池被旧任务塞满。
    3. 哈希构建成本：ResultSet 中 200 百万项的 `unordered_map` 构建耗时过长。
    4. 内存抖动：循环内频繁构造 QString 对象。
- **建议方案**：实施无锁快照搜索与零分配筛选。

### 2. 交互逻辑规约 (Plan-154 补充)
- **左键逻辑**：盘符按钮左键仅用于 FilterState 切换，严禁触发数据库加载。
- **右键逻辑**：提供显式的“加载数据”菜单，引导用户按需管理内存。
- **粘贴屏蔽**：彻底移除粘贴功能，改为状态栏提示。

### 3. 数据加载策略 (Plan-155)
- **目标**：废除分页加载机制，实现搜索结果全量映射。
- **核心要求**：rowCount 始终返回真实结果数，移除 fetchMore 逻辑。
- **风险规避**：必须依赖异步投影排序与无锁化渲染以减轻 UI 线程计算压力。

### 4. 预览功能集成 (Plan-157)
- **目标**：复刻 ArcMeta 的“原始优雅版”QuickLook 空格键预览。
- **UI 规约**：
    - 必须为**居中悬浮窗**（非全屏），圆角 12px，样式对标截图。
    - 预览透明图像必须显示**棋盘格背景**（#2B2B2B / #333333 瓦片）。
    - 集成 `ToolTipOverlay` 提示引擎，在切换/打分时显示巨大的半透明图标反馈。
- **文本对标 Notepad++**：
    - 实现 GBK/UTF-8 编码自适应探测。
    - 二进制安全拦截（遇 0x00 字节停止渲染或提示）。
    - 仅读取头部 128KB 保证百万级文件下的瞬间响应。

### 5. 图像预览模糊与工业级重构规约 (Plan-165)
- **目标**：解决 QuickLookWindow 预览图像模糊的问题，实现放大仍保持极清的工业级预览。
- **核心要求**：
    - **SVG 矢量还原**：彻底摆脱固定 1024x1024 栅格化限制。引入视口/DPI 联动技术，使 SVG 的渲染分辨率动态对齐物理视口尺寸，且在鼠标滚轮放大时实时、无损地重绘渲染，达到无限清晰。
    - **超高分辨率/特殊格式分级渐进加载**：对于 RAW, PSD, TIFF, AI, EPS 等高精格式，在首次载入时，快速抓取高清晰度缩略图（如原先的 ShellThumbnail 或 Qt 原生加载，提升尺寸至最大 2048/4096 px）；在鼠标缩放、平移且操作停止后，执行异步渐进式高质量纹理重绘与超采样重建。
    - **动态高清重绘管线**：`QuickLookGraphicsView` 在 wheelEvent 缩放后，不再仅通过矩阵物理拉伸纹理，而是通过轻量级延时定时器触发 `requestHighDpiRender`，利用当前实际视口（Viewport）的物理尺寸重新请求无损图片源或进行平滑重构。

### 6. 消除首屏默认图标闪烁与二级双轨缓冲重构规约 (Plan-166)
- **目标**：重构缩略图加载与渲染架构，彻底根治数据过滤/筛选后，首次显示数据时“先闪系统默认图标，然后才显示缩略图”的傻逼逻辑体验，实现瞬间、无闪烁的高保真缩略图首屏级展现。
- **核心要求**：
    - **二级高速双轨缓冲（Tiered-Buffer）**：将 L1 内存高速缓存 (`m_thumbCache`) 与 L2 磁盘持久缓存（`thumbs/` 目录）进行逻辑打通。在 UI 线程执行 `data()` 时，若 L1 缺失但检测到 L2 磁盘物理缓存已就绪，严禁回退渲染默认图标，而是快速同步载入本地轻量 PNG 缓存，或保持等待状态渲染占位轮廓。
    - **首屏预测性异步预热（Predictive Pre-warming）**：重构 `ScanController` 的结果集交付流程。当计算出新筛选结果后，交付 UI（`resultsSwapped`）前，在子线程对前排 50 项（首屏可视极限）执行预测性高优先加载，提前读取对应的 L2 磁盘缓存并同步至 L1 内存缓存，从而确保 UI 重塑（Reset）时，首屏图片 100% 已在内存就位。
    - **精细化重置清理策略**：在 `updateResults` 中发生大批量重置时，废除一刀切擦除所有加载标志的过激行为，引入“增量差分刷新”与“保留存量高频标记”的刷新算法，平滑过滤切换瞬间的视觉过渡。
